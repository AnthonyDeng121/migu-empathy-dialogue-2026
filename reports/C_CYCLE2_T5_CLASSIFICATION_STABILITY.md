# C Cycle2 T5：分类稳定性与训练推理一致性

日期：2026-10-30（Asia/Shanghai）。状态：本机复核完成，进入 Integration Gate，等待 D 同行审查。此次只做复算与稳定性检查，不训练、不改权重、不调阈值。

## 结论

- 画像 v1 packaged checkpoint 在固定 B1 validation 上重载复现 2,354/2,354 条既有画像标签。画像训练输入格式与正式 checkpoint 推理格式逐条一致；完整评测的 macro exact 为 **0.646842**，高于全空基线 **0.628292**。但任一维非空的预测 precision 为 **0.9043**、recall 仅 **0.3577**；提升主要来自 interests。长历史（≥16 条）macro exact 为 **0.556185**，只比对应全空基线 **0.548631** 高 0.007554（该切片 n=353），不据此承诺稳定泛化。
- 情感权重 0.65 checkpoint 的正式推理入口对 2,354 条复算得到 Accuracy **0.714953**、Macro-F1 **0.590474**，与 C T4 报告一致。按历史长度分层，Macro-F1 从短历史 0.585315 到长历史 0.489934；`care` 三个切片都为 0，长尾问题没有解决。
- 概率校准只作事后诊断，没有用 validation 调阈值：画像三维 10-bin ECE 为 0.0615–0.0873；情感 top-label 15-bin ECE 为 **0.0879**，NLL 为 **0.9397**。这些数值没有官方门槛，也不是盲测。
- 结论：画像 v1 继续保留为内部候选；情感 0.65 继续不替换 Day5 默认模型；没有证据支持上线新阈值或改动正式配置。
