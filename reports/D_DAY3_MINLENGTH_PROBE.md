# D 岗位 Day 3：D3 探针——最短生成长度下限（假设被推翻）

**状态：Done（本轮推理与指标已完成并入档）。** `reports/D_DAY3_ORIGINAL_MODEL_VAL_FULL.md` 的三方对比暴露了一个失败模式：D2 有 32 条近空回复（≤6 字符，1.4%），原模型 0 条。当时判断"若要继续优化（D3），近空回复是最明确的靶子"。本报告用最便宜的干预验证这个假设——给推理加最短生成长度下限，不重训。

**结论：假设不成立，不要加这个下限。** 下限能把近空回复清零，但整体指标下降 1.1–1.3%，且推理慢 2.29 倍。那 32 条短回复大多是模型在**正确**匹配极短金标，强行续写只会得到通用填充料。

## 为什么假设被推翻

看那 32 条被强行续写之后的样子，原因很清楚：

| sample_id | 原输出（≤6 字符） | 加下限后的输出（前 90 字符） |
|---|---|---|
| `pp:["val_conv_000024",5,1]` | `嗯，我在听。` | `嗯，我在听。那种怕一旦停止，连最微小的控制力都会消失的感觉，确实挺让人想抓住点什么的。\n\n那就先这样，不用急着整理思路……` |
| `pp:["val_conv_000053",5,1]` | `嗯，我在听。` | `嗯，我在听。那种"怎么努力都没用"的无力感确实很沉重，像是被绑住了手脚，连方向都不知道往哪走。\n\n你慢慢说，我在这儿听着。` |
| `pp:["val_conv_000060",3,1]` | `好，我听着。` | `好，我听着。请继续。\n> \n> 你不需要为我的耐心感到抱歉。我在听，不是为了给你找答案，而是想确认一下……` |
| `pp:["val_conv_000074",5,1]` | `嗯，我在听。` | `嗯，我在听。你继续说，不用管逻辑，想到哪里说到哪里都行。` |

模型说完"嗯，我在听。"时**它已经说完了**——这些点的金标正是"我在。"、"我听着。"这类极短确认。下限把 EOS 的 logit 压成 -inf，逼它在本该收尾的地方继续，吐出来的是**通用填充料**，第三例甚至产生了畸形的 markdown 引用块（`\n> \n>`）。

所以"近空回复是缺陷"这个判断是错的：它主要是模型正确学到了短确认语域的表现（这与 `D_DAY3_ORIGINAL_MODEL_VAL_FULL.md` 的发现一致——D2 相对原模型的收益正来自学会这个语域）。**用长度下限去"修"它，是在修一个好的行为。**

## 结论

1. **不要加最短生成长度下限。** 收益是消灭一个并非缺陷的现象，代价是指标 −1.1%/−1.3% 且推理慢 2.29 倍。
2. **`--min-new-tokens` 参数保留在脚本里但默认关闭**（默认 0 且不传进 `generate()`，已记录运行仍可字节复现），供将来确有需要时使用；不建议在当前候选上启用。
3. **D3 需要换靶子。** 若要继续优化，方向不再是"压制短回复"，而应是**提升长回复的质量**（D2 平均 135.9 字符、中位 90，而低分切片里原模型那种过度泛化的长篇安抚正是 D2 已经修好一部分的问题；剩下的空间在内容针对性，不在长度）。
